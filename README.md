# 🍞 Bakery Website

A modern and elegant static website template for a bakery, built using HTML, CSS.

📘 Overview

This project represents a Bakery landing website called “Family Bakery”, designed to showcase a bakery’s products, story, and contact details in a visually appealing layout.
The website includes multiple sections such as Home, About, Our Offer, Gallery, Blog, and Contact.


🛠️ Technologies Used

HTML5

CSS3

GitHub Pages for deployment
