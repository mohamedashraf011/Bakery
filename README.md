# Bakery

🍞 Bakery Website

A modern and elegant static website template for a bakery, built using HTML, CSS, and a bit of JavaScript.

🔗 Live Demo: mohamedashraf011.github.io/Bakery

📘 Overview

This project represents a Bakery landing website called “Family Bakery”, designed to showcase a bakery’s products, story, and contact details in a visually appealing layout.
The website includes multiple sections such as Home, About, Our Offer, Gallery, Blog, and Contact.

✨ Features

Clean and modern design using HTML5 and CSS3

Fully responsive layout for desktop and mobile devices

Dedicated sections for bakery products and offers

Gallery page to highlight featured items

Contact page with a map and basic contact info

Hosted live using GitHub Pages

🛠️ Technologies Used

HTML5

CSS3

JavaScript (Vanilla)

GitHub Pages for deployment
